# Export Studio — User Guide

Open **Export Studio** from the sidebar (Data Architecture group) or `/export-studio`.

## 1. Choose a template

The Template dropdown lists all 6 catalog templates. Templates marked **"(Not available yet)"** — Pharmacist Performance, Evaluation Results — cannot be generated yet; the page shows exactly why underneath the selectors.

## 2. Fill in the selectors

Each template only shows the selectors it actually needs:
- **Month** — required for Executive/Branch/KPI Performance.
- **Branch** — required for Branch Performance; optional (defaults to all your authorized branches) elsewhere.
- **KPI** — required for KPI Performance. The dropdown only lists active, registry-known KPIs.
- **Include Raw Data** — adds an extra sheet with the underlying rows, where the template supports it.
- **Format** — XLSX or CSV, depending on what the template supports.

You will only ever see branches you're authorized to see — the same scope rules as the rest of PharmaPulse.

## 3. Review the Preview Summary

Before generating, the page shows the template name, version, and expected sheet list, plus any known limitations for that template (e.g. "Pharmacist Contribution sheet is deferred").

## 4. Generate & Download

Click **Generate & Download**. The export is validated before any file is written:
- If validation finds a blocking problem (e.g. the selection would produce too many rows), **no file is downloaded** — you'll see the exact reason.
- If the dataset is simply empty (no rows matched your filters), the workbook still downloads with headers and a Definitions sheet — it tells you what would have appeared.

## 5. Workbook contents

Every Excel export includes:
- A **Cover** sheet — report title, scope, period, generated date, generated by, workbook version, and confidentiality classification.
- Your analytical sheets (e.g. Branch Summary, KPI Performance).
- An optional **Raw Data** sheet, if you checked "Include Raw Data."
- A **Definitions** sheet explaining every metric, its formula, unit, and how missing targets/blanks are handled.

## 6. CSV exports

CSV downloads are UTF-8 with a BOM (so Arabic text displays correctly in Excel), with a fixed, predictable column order matching the workbook's own columns.

## 7. PDF

PDF export is **not available yet**. There is no PDF capability in PharmaPulse today — this is shown honestly in the UI rather than offering a broken or fake PDF option.

## 8. Recent Exports

The bottom of the page (Admin only) shows your most recent exports — template, scope, format, status, and row count — so you can confirm what was generated without re-running it.
